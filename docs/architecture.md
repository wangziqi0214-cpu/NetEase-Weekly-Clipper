# 一体化系统架构

本仓库不是两个独立项目，而是一条从发现新歌到交付视频的完整生产流水线。

```text
QQ 音乐 / 网易云音乐 / KKBOX 新发行采集
                    ↓
              去重与机器初筛
                    ↓
          React 人工审批、排序与定稿
                    ↓
             网易云周更歌单发布
                    ↓
       资料研究 → TTS → 片头 → 歌曲正片
                    ↓
             整片渲染与发布文案
```

## 目录与职责

| 目录 | 职责 |
| --- | --- |
| `song_discovery/` | 三平台采集、去重机筛、反馈学习、审批 API、网易云发布及视频任务衔接 |
| `review_workbench/` | 运行在 8502 端口的新歌人工审批前端；`src/` 是源码，`dist/` 是当前可运行构建 |
| `run.py`、`src/` | 歌曲素材抓取、研究、TTS、片头、歌曲播放和整片渲染 |
| `pyncm/` | 网易云数据访问兼容层 |
| `config/`、`assets/` | 视频版式及仓库内可公开的静态资源 |
| `chrome_extension/` | KKBOX 浏览器采集备用方案 |
| `scripts/launchd/` | 每日采集、开机启动和本地后台服务 |
| `tests/` | 审批、采集、发布、视频衔接和浏览器扩展的回归测试 |

## 本地数据边界

`output/`、SQLite 数据库、下载的歌曲和封面、TTS 模型、克隆音色、日志、Cookie 与 `.env` 都是本机运行数据或敏感资料，不上传 Git。审批系统的代码、前端源码与可运行前端构建均属于本项目并纳入仓库。
