# 华语新歌三合一发现中枢 (NetEase Weekly Clipper) 使用指南

本工具是一个**真正的三合一华语新歌发现、人审与周刊歌单自动发布中枢**。QQ音乐、网易云音乐、KKBOX 为底层三个平等的原生数据源适配器。

日常使用仅需打开唯一的控制台界面：[**http://127.0.0.1:8502**](http://127.0.0.1:8502)。

---

## 1. 整体架构与工作流

```
                    ┌────────────────────────────────────────────────────────┐
                    │      统一控制台: http://127.0.0.1:8502 (或 CLI)         │
                    │      - 三大数据源状态看板 (QQ / NetEase / KKBOX)        │
                    │      - 唯一「🔄 立即更新三平台」采集触发按钮              │
                    │      - 统一候选池人审决策 (通过/拒绝/批量操作)           │
                    │      - 一键发布/追加至网易云周刊歌单                    │
                    └──────────────────────────┬─────────────────────────────┘
                                               │
                                   [本地常驻守护进程: Supervisor]
                                               │
               ┌───────────────────────────────┼───────────────────────────────┐
               ▼                               ▼                               ▼
       [QQ 音乐适配器]                [网易云音乐适配器]              [KKBOX 会话适配器]
     (官方 Web/Client API)          (本地 API + cookie.txt)      (后台隐形 Bridge Sidecar)
```

## 2. 一次性准备工作（仅需配置一次）

本系统的核心原则是：**所有登录态和环境依赖仅在初始化时配置一次，日常运维无需干预。**

### 步骤 1：网易云登录态准备
将登录后的网易云 Netscape 格式 Cookie 保存至项目根目录的 `cookie.txt`。

### 步骤 2：KKBOX 会话适配器初始化（一次性）
1. 开启代理软件的 **台湾 (TW)** 或 **香港 (HK)** 节点；
2. 打开 Google Chrome，访问并登录一次 [play.kkbox.com](https://play.kkbox.com)；
3. 进入 `chrome://extensions/` 开启「开发者模式」，点击「加载已解压的扩展程序」，选择项目中的 `chrome_extension/kkbox_collector` 目录。
   *(注：扩展仅作为后台静默的 KKBOX 登录会话 Sidecar，日常无需打开或操作插件弹窗)*

### 步骤 3：安装 macOS 后台开机守护服务
在项目终端执行一次安装脚本：
```bash
./scripts/launchd/install_launchd.sh
```

## 3. 日常使用步骤（唯一的日常工作流）

当后台采集到新歌并完成初筛后，macOS 桌面将弹出通知提醒。

### 步骤 1：打开统一控制台
浏览器访问：[**http://127.0.0.1:8502**](http://127.0.0.1:8502)

### 步骤 2：查看数据源状态与即时更新
- 页面顶部实时显示 **QQ音乐**、**网易云音乐**、**KKBOX** 三大适配器的入库候选数、健康状态与最近采集时间；
- 如需立即采集最新新歌，点击顶部 **「🔄 立即更新三平台」** 按钮，系统将自动并发刷新 QQ、网易云并通知 KKBOX 会话 Sidecar 采集。

### 步骤 3：审核曲目决策
- 在列表中查看各平台候选曲目的标题、歌手、专辑、选曲规则及评分依据；
- 点击单曲标记（`approved` / `rejected` / `deferred`）或使用顶部的「批量操作与保存」。

### 步骤 4：一键发布至网易云周刊歌单
1. 审核完毕（待审核 `pending = 0`）后，滚动至页面底部；
2. 点击 **「🔍 预览发布规划 (Dry Run 预演)」** 校验跨平台歌曲匹配；
3. 点击 **「🎵 确认发布至网易云歌单」**，系统自动创建或追加至当周周刊歌单，并生成直达链接。

## 4. CLI 常用指令

```bash
# 查看三平台适配器与候选池健康状态
python3 -m song_discovery.cli status

# 命令行立即执行全平台采集
python3 -m song_discovery.cli collect --platform all

# 命令行查看数据库详细统计
python3 -m song_discovery.cli stats

# 检查网易云登录态
python3 -m song_discovery.cli login-status --cookie-file cookie.txt
```
