# 华语新歌三合一发现系统与周刊歌单自动发布中枢 (Discovery MVP)

## 1. 系统架构与模块总览

本系统为真正的三合一新歌采集、筛选、人审与网易云歌单发布中枢：

```
[三数据源适配器: QQ (官方API) / 网易云 (15页窗口) / KKBOX (后台会话Sidecar)]
                                │
                                ▼
                     [统一 Release/Track 模型]
                                │
                                ▼
                  [物理选曲规则: select_track]
                  - single: 选第1首原曲 (即使含伴奏等2首及以上)
                  - album / 多曲 EP (>=2首): 选第2首
                  - 任意单曲目发行: 选唯一曲目
                                │
                                ▼
                   [高召回评分器: RelevanceScorer]
                   (排除白噪音/有声书，摇滚/乐队加分)
                                │
                                ▼
                   [SQLite 幂等持久化: DiscoveryDB]
                                │
                                ▼
                [常驻守护进程: DiscoverySupervisor]
                - 127.0.0.1:8765 内嵌 KKBOX HTTP 桥接与命令队列
                - 127.0.0.1:8502 无头托管 Streamlit 统一后台
                - 每天北京时间 01:00 自动运行 QQ + 网易云 + KKBOX 采集，并在服务启动时立即更新
                - 消费 Web UI / CLI 下发的「立即更新三平台」命令
                - macOS 桌面防刷防抖横幅通知
                                │
                                ▼ (唯一的交互卡点)
               [Streamlit 人审界面: song_discovery/app.py]
               - 顶部 QQ / 网易云 / KKBOX 三数据源平等状态卡
               - 唯一的「🔄 立即更新三平台」一键刷新按钮
               - 候选曲目流派与选曲决策复核 (批量通过/拒绝)
               - 待审判定: pending=0 触发发布就绪
                                │
                                ▼
            [网易云周刊歌单发布区: NetEasePublisher]
            - 🔍 预览发布规划 (Dry Run 预演)
            - 原生网易云 ID 直接复用
            - 跨平台曲目 (QQ / KKBOX) 通过 /cloudsearch 保守正则匹配
            - 存疑 (Ambiguous) / 未匹配 (Unmatched) 安全跳过
                                │
                                ▼
            [🚀 确认发布 / 追加至网易云周刊歌单 (Idempotent)]
```

---

## 2. 核心模块与设计原则

1. **三平台平等适配器**：
   - QQ 音乐：通过官方 API 直接抓取华语与港台新歌；
   - 网易云音乐：通过本地服务与 Cookie 抓取最新新碟（15页窗口）；
   - KKBOX：通过后台静默会话 Sidecar（Chrome 扩展在本地 8765 桥接下发命令后无感抓取），三者在数据模型与看板上完全平级。
2. **唯一交互入口**：
   - 统一使用 `http://127.0.0.1:8502` 查看三平台健康状态、触发全平台更新、审核曲目并一键发布歌单。
3. **单点人审发布防线**：
   - 发布前必须完成全部待审曲目审核（`pending == 0`）；
   - 必须通过 Dry-Run 预演校验当前曲目池与歌单目标水印，方可执行真实发布。
